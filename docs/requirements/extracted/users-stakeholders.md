
### کاربران اصلی سیستم

| نقش                                       | نوع        | هدف / نیاز اصلی                                               |
| ----------------------------------------- | ---------- | ------------------------------------------------------------- |
| **بیمار (Patient)**                       | کاربر اصلی | پیدا کردن پزشک، مشاهده زمان‌های آزاد، رزرو، مشاهده و لغو نوبت |
| **پزشک (Doctor)**                         | کاربر اصلی | مشاهده برنامه کاری و نوبت‌های ثبت‌شده                         |
| **پذیرش / کارکنان کلینیک (Receptionist)** | کاربر اصلی | مدیریت پزشکان، برنامه کاری و نوبت‌ها                          |

### ذی‌نفعان سیستم

| ذی‌نفع                        | نقش / منفعت                                                       |
| ----------------------------- | ----------------------------------------------------------------- |
| **بیماران**                   | دریافت تجربه ساده، سریع و قابل‌اعتماد برای نوبت‌دهی               |
| **پزشکان**                    | مدیریت و مشاهده برنامه و نوبت‌های خود                             |
| **پذیرش کلینیک**              | کاهش کار دستی و مدیریت نوبت‌ها و برنامه پزشکان                    |
| **مدیریت کلینیک**             | بهبود فرآیند نوبت‌دهی، کاهش تماس‌های تلفنی و افزایش قابلیت اعتماد |
| **تیم محصول / PM**            | تحقق اهداف محصول و سنجش موفقیت آن                                 |
| **تیم توسعه و معماری**        | طراحی و پیاده‌سازی سیستمی ساده، قابل‌اعتماد و قابل توسعه          |
| **مسئول امنیت / مدیریت داده** | حفاظت از اطلاعات شخصی و حساس بیماران                              |
