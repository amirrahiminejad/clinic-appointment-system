# Patient Context Language

## Terms

| Term | Meaning |
| --- | --- |
| `Patient` | بیمار دارای پروفایل در سامانه |
| `Patient Profile` | اطلاعات اصلی و قابل ویرایش بیمار |
| `Patient Contact Info` | داده‌های تماس برای اطلاع‌رسانی |
| `Patient Status` | وضعیت فعال/غیرفعال یا قابل‌استفاده بودن بیمار |

## Clarifications

- `Patient` با `User Account` الزاماً یکی نیست.
- `Patient Contact Info` برای Notification مصرف می‌شود، اما خود Notification در این context مدیریت نمی‌شود.
